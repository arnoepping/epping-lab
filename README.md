# EPPING Logo Lab

Playground for the EPPING logo and colour schemes. Static, no build: `index.html` + `lab.js` + `lab.css`.
Fonts come from Fontsource on jsdelivr and are outlined with opentype.js, so exported SVGs are paths.

- Gallery: preset variants with IDs (P = palettes, S = styles, F = fonts, W = weights), plus random sets.
- Editor: live controls, settings kept in the URL hash (Copy link to share), and SVG/PNG/icon export.
- Local: `python3 -m http.server` and open http://localhost:8000.
- Live: GitHub Pages from `main` (root).

The final logo moves to the EPPING repo (`scripts/build-logo.mjs`).
